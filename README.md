# Personal Dashboard

Personal dashboard built with React and Vite to document and showcase the projects I create while learning frontend development.

## Tech Stack

| Category             | Technology                          |
| -------------------- | ----------------------------------- |
| **Framework**        | React 19 + Vite 8                   |
| **Language**         | JavaScript (ES6+)                   |
| **Routing**          | React Router 7.14+                  |
| **Syling**           | TailwindCSS4                        |

## Getting Started

1. **Install dependencies**

   ```bash
   npm install
   ```

2. **Start development server**

   ```bash
   npm run dev
   ```

   Server runs at `http://localhost:5173`
